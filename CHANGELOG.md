# Changelog

## 0.2.0 — 2026-09-26

First public release.

- Local Codex app-server integration with the installed imagegen skill and
  existing ChatGPT login; persistent SQLite image library.
- Responsive creative workspace with independent desktop scrolling, persistent
  generation controls, larger text and progressive brief options.
- Reference upload/paste/drop, edit roles, original comparison, seven starters,
  exact text, framing, transparency and 1–4 serial variations.
- Unfinished-draft recovery, keyboard navigation, focus restoration and undo.
- Search, sort, grid density, favorites, archive, downloads and prompt export.
- Connection diagnostics, explicit refresh, pause/resume and cancellation.
- MIT license, contributor/security guides and credential-free fixture CI.
